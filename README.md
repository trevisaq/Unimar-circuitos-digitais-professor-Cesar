# Organização do projeto

Para conseguir executar os arquivos, é necessário a instalação de um programa diferente por pasta raíz.

- Na pasta **LOGSIN** é necessário o instalar o programa "logsin-win-2.7.1" ou versões semelhantes.
- Na pasta **TABLEROS** é necessário o instalar o programa "ConstructorVirtualDeCircuitos".

`Dentro de cada pasta raíz, os arquivos listados / separados são os referentes aos programas necessários.`
